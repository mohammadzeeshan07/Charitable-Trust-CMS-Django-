# 🌟 Hope Foundation CMS

A Charity Management System developed using **Django** and **Bootstrap 5**. This project helps charitable organizations manage programs, banners, gallery images, and contact messages through an admin dashboard.

---

## 📌 Features

- 🏠 Responsive Home Page
- 📖 About Page
- 📚 Programs Management
- 🖼 Gallery Management
- 📩 Contact Form
- 🖼 Dynamic Banner Section
- 🔎 Search Functionality
- 📄 Pagination
- 📊 Custom Dashboard
- ➕ Add Program
- ✏ Edit Program
- 🗑 Delete Program
- 📬 Latest Contact Messages
- 🔐 Django Admin Panel
- 🎨 Bootstrap 5 Responsive UI

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/hope-foundation-cms.git
```

### 2. Move into Project

```bash
cd hope-foundation-cms
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply Migrations

```bash
python manage.py migrate
```

### 7. Create Superuser

```bash
python manage.py createsuperuser
```

### 8. Run Server

```bash
python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
